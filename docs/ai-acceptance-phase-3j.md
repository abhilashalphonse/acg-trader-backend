## Release decision
This phase is offline acceptance only, not approval to activate real money or inference. 3K must run exact candidate in isolated staging, verify disabled production boundaries and trading regression before any authorized merge/deploy. Live activation remains blocked by actual provider transport/key custody, model and billing validation, production market-data entitlement/consent and DLP, durable distributed budgets and BYO request idempotency, commercial pricing, merchant approval and reconciliation, operational audit/incident controls, real failover and sustained production-equivalent load acceptance. No real data export, keys, paid inference, payment, credit sale, production config or collections changed. Results must be taken from completed CI logs, not inferred from code submission.
